# YachtApp

C++で制作した、サイコロゲーム「Yacht（ヨット）」のコンソールアプリケーションです。

5個のサイコロを振り、最大2回まで任意のサイコロを振り直しながら役を作ります。
全12ラウンドをプレイし、最終的な合計得点を競います。

現在はPlayer AとPlayer Bによる2人対戦に対応しています。

## 主な機能

- 5個のサイコロを使用
- 1ターンにつき最大2回まで振り直し可能
- 振り直すサイコロを個別に選択可能
- 12種類のスコアカテゴリー
- 使用済みカテゴリーの再選択防止
- 全12ラウンドのスコア管理
- Aces～Sixesの合計が63点以上の場合、35点のボーナスを加算
- Player A / Player Bによる2人対戦
- 最終スコアによる勝敗判定

## スコアカテゴリー

| Category | Score |
|---|---|
| Aces | 1の出目の合計 |
| Deuces | 2の出目の合計 |
| Threes | 3の出目の合計 |
| Fours | 4の出目の合計 |
| Fives | 5の出目の合計 |
| Sixes | 6の出目の合計 |
| Choice | 5個のサイコロの合計 |
| Four Dice | 同じ目が4個以上の場合、5個の合計 |
| Full House | 同じ目3個 + 別の同じ目2個の場合、5個の合計 |
| Small Straight | 4つ以上の連続した出目で15点 |
| Big Straight | 5つの連続した出目で30点 |
| Yacht | 5個すべて同じ出目で50点 |

### ボーナス

Aces、Deuces、Threes、Fours、Fives、Sixesの合計が63点以上の場合、35点のボーナスが加算されます。

## 遊び方

1. Player Aが5個のサイコロを振ります。
2. 必要に応じてサイコロを選択し、最大2回まで振り直します。
3. 最終的な出目から、得点を記録するカテゴリーを1つ選択します。
4. Player Bも同様にプレイします。
5. これを全12ラウンド行います。
6. 12カテゴリーの得点とボーナスを合計します。
7. 合計得点が高いプレイヤーが勝利します。

### プロジェクト間の関係

```text
        ┌─────────┐
        │   Core  │
        └────▲────┘
             │
       ┌─────┴─────┐
       │           │
┌──────┴─────┐ ┌───┴─────┐
│  Console   │ │   GUI   │
└────────────┘ └─────────┘
```

`Core` にゲームのロジックを集約し、`Console` と `GUI` から共通して利用できる構成にしています。

### Core

画面表示に依存しない、ゲームの基本ロジックを担当します。

**Game**
ゲーム全体の状態、12ラウンドの進行、Player A / Player Bの管理、ターン順、ゲーム終了判定、勝敗判定を担当します。

**Dice**
サイコロの生成、出目の管理、振り直しなどのサイコロに関するロジックを担当します。

**Score**
各役の得点計算、スコア、ボーナス、合計得点の管理を担当します。

### Console

コンソール版のゲーム進行や入出力を担当します。ゲームロジックには `Core` を利用します。

**main.cpp**
コンソールアプリケーションのエントリーポイントです。

**ConsoleGame**
Coreで管理されているゲームの状態や進行に従い、ターンや最終結果などのコンソール表示とユーザー入力を担当します。

**ConsoleDice**
サイコロのコンソール表示を担当します。

**ConsoleScore**
役の一覧や得点、スコア表など、スコアに関するコンソール表示を担当します。

### GUI

GUI版のアプリケーションを実装するためのプロジェクトです。

ゲームロジックには `Core` を利用し、今後GUI固有の画面表示やユーザー操作を実装します。
